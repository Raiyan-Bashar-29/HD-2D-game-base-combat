# Yoshimura Eto

Sprites and sounds from the M.U.G.E.N character "Yoshimura Eto" by **刃下心**.
Unpacked by `tools/mugen_sprites.gd`. Used with the owner's say-so; keep this file with them.

The author's notice (人物声明.txt): every sprite was drawn by the author; the character must not
be used for profit of any kind (no selling, no livestreaming, no resale). This project is not
sold; it is for community development. Approved for this repository by the owner on
2026-11-15. Only the sounds the converted moves play are kept.
