# For any AI agent or new contributor

This is the **combat fork** of an HD-2D game base template (Godot 4.7.2, GDScript).

Read these, in order:

1. **[`docs/HANDOFF.md`](docs/HANDOFF.md)**: the start-here page. It covers where things stand,
   how to pick up the work, the commands that prove a change works, and a plain-words map of the
   code.
2. **[`CLAUDE.md`](CLAUDE.md)**: the project rules. They apply to every tool, not only Claude.
3. **[`docs/COMBAT.md`](docs/COMBAT.md)**: the phases, the board and the releases. The first row
   not marked DONE is the next package.

Never read `docs/DEVLOG.md` whole; it is very long. Find an entry by its `## date — id` header.
